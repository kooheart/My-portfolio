# Responsive Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript**. The website showcases my introduction, skills, projects, and contact information in a clean and user-friendly layout.

## ✨ Features

* Responsive portfolio layout
* Navigation menu
* Home and About sections
* Skills showcase
* Project portfolio
* Project category filtering
* Contact form with JavaScript validation
* Dark mode / light mode
* Mobile-friendly navigation
* Responsive design for desktop, tablet, and mobile devices
* Accessible form labels and navigation controls

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic elements
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Interactivity, form validation, project filtering, navigation, and theme switching
* **GitHub Pages** – Website deployment

## 📁 Project Structure

my-portfolio/

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the portfolio and test the interactive features.

## 📱 Responsive Design

The website uses CSS media queries to adapt the layout for different screen sizes, including:

* Desktop
* Tablet
* Mobile
* Small mobile devices

## ♿ Accessibility

Accessibility features included in the project include:

* Semantic HTML elements
* Descriptive page metadata
* Labels for form fields
* Accessible navigation controls
* ARIA attributes for interactive elements
* Keyboard-friendly form controls

## 📌 Project Purpose

This project was created as part of a web development course to demonstrate the use of **HTML, CSS, and JavaScript** to design, develop, test, and deploy a responsive portfolio website.
